# Mobv VOC 분류·검토 자동화 도구 구축 — 최종 보고서

작성일: 2026-10-20
범위: 모바일 앱과 분리된 VOC 운영 도구 (가상 데이터 검증)

## 프로젝트 목적

Mobv의 VOC 운영을 시작하기 전, 앞으로 들어올 의견을 어떻게 분류하고 누가 검토할지 정했다. CSV로 받은 의견의 유형·제품 영역·우선순위·담당을 정리하고, 위험하거나 애매한 건은 사람이 확인하도록 도구를 만들었다. 아래 결과는 실제 운영 실적이 아니라 가상 의견으로 이 흐름을 확인한 기록이다.

## 구현한 흐름

`CSV 업로드 → 입력 검증·연락처 마스킹 → AI 또는 규칙 초안 분류 → 운영 기준 적용 → 검토 대기 추출 → 사람 승인·수정 → 운영 현황·보고서 확인`

- 입력 CSV의 열·날짜·중복 ID를 검사한다. 이메일과 휴대전화 형식은 모델 호출 전에 마스킹한다.
- AI 분류 결과와 운영 기준 결과를 구분해 보여준다. 개인정보 노출처럼 즉시 확인이 필요한 항목은 운영 기준으로 우선순위를 보정한다.
- 검토가 필요한 의견은 운영자가 승인하거나 수정 이유를 남긴다. 원래 분류 파일은 유지하고 검토 결과를 별도 파일에 저장한다.
- 대시보드에서 의견 목록·상세, 처리 현황과 접수일·제품 영역·채널·유형·우선순위별 분포, 실행 기록을 확인한다. 분류 CSV와 Markdown 운영 요약을 내려받을 수 있다.
- 새 분류 작업마다 `weekly_report.md`를 만든다. 파일 이름과 달리 특정 한 주가 아닌 해당 CSV의 **전체 입력 기간**을 요약한다.

## 데모 결과와 확인 범위

2026년 10월 1~15일에 걸친 **가상 VOC 30건**을 `gpt-6-luna`로 분류했다. 30건 모두 처리됐고 분류 실패는 없었다. 사람 검토 대기 17건은 그대로 남겨뒀으며 승인 완료는 0건이다. 운영 기준을 적용한 잠정 결과에서 P0는 2건, P1은 10건이었다. [운영 요약](../output/openai/weekly_report.md)에는 우선 확인할 의견과 접수일·제품 영역·채널·유형·우선순위별 건수를 담았다. 이 분포는 가상 데이터 한 묶음에서 나온 결과다.

별도의 가상 20건에는 **규칙 초안** `heuristic-draft-v0`를 적용해 독립 평가했다. 주요 6개 항목이 모두 일치한 건은 5/20이었다. 이 값은 OpenAI 모델의 정확도가 아니다. 수작업 기준선과 처리시간·정확도 목표는 이번에 측정하지 않았다. 따라서 사람 대비 시간 절감률이나 AI 정확도 목표 달성 여부도 제시하지 않는다. 평가 조건과 항목별 결과는 [독립 평가 기록](evaluation-results-2026-10-20.md)에 남겼다.

## 시연과 제출 자료

- 비공개 데모: [Mobv VOC 운영 센터](https://mobv-voc-op.streamlit.app/) — 접근 권한이 있는 계정으로 로그인해야 한다.
- VOC 전용 소스: 비공개 `RedHareTeam/mobv` 저장소의 `voc-ops` 브랜치. 앱 코드인 `lib`은 이 브랜치에 포함하지 않았다.
- 실행·검토·배포 안내: [README](../README.md)
- 산출물 형식: [출력 스키마](output-schema.md)
- 가상 VOC 처리 결과: [분류 CSV](../output/openai/classified_voc.csv), [운영 요약](../output/openai/weekly_report.md). 검토 대기 17건은 대시보드의 **검토 작업**에서 확인할 수 있다.
- 검토 화면 예시: [대시보드 캡처](images/review.png)

시연 순서는 **운영 현황**에서 분포와 우선 확인 의견을 보고, **검토 작업**에서 목록·상세와 AI/운영 기준 결과를 비교한 뒤, **실행 기록**에서 CSV와 Markdown을 내려받는 것이다. 실제 승인 버튼은 최종 판단 권한이 있는 사람이 사용할 때만 누른다.

## 남은 운영 과제

검토 대기 17건은 가상 데이터에서 생성된 데모 상태이며, 아직 사람이 승인·수정하지 않았다. 현재 배포는 가상 데이터로 흐름을 살펴보는 용도다. 업로드와 검토 결과를 실행 환경의 임시 파일에 저장하므로 재시작이나 재배포 후 보존을 보장하지 않는다. 실제 고객 VOC를 다루기 전에는 로그인·권한, 영속 저장소, 개인정보 처리 범위, 감사 기록과 장애 대응을 갖춰야 한다. 실제 운영 성과는 운영을 시작한 뒤 별도로 측정해야 한다. 실서비스 전환과 모바일 앱 배포는 이번 결과물의 범위가 아니다.

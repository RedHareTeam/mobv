## 평가 범위와 방법

- 입력: `data/evaluation_voc.csv` 20건만 분류기에 전달했다.
- 정답: 분류 결과와 실행 로그가 저장된 뒤 `data/evaluation_gold.csv`를 열어 비교했다.
- 엔진: `heuristic-draft-v0` (기본 규칙 초안, 외부 모델 호출 없음)
- 정책 버전: `v1.0`
- 실행 명령:

  ```powershell
  .\.venv\Scripts\python.exe scripts\classify_voc.py `
    --input data\evaluation_voc.csv `
    --output-dir output\evaluation_draft
  ```

- 결과 파일은 로컬 `output/evaluation_draft/`에 생성했다. 정답 데이터는 입력이나 예측에 포함하지 않았다.
- 평가 세트에 맞춘 규칙·프롬프트 변경은 하지 않았다.

## 해석과 한계

- 이 결과는 **기본 규칙 초안만의 기준 결과**이며, 실제 OpenAI 모델의 평가 결과가 아니다. 모델 호출은 별도의 API 비용이 발생할 수 있으므로 이 실행에는 포함하지 않았다.
- 20건의 가상 평가 세트 한 번에서 얻은 결과이며, 실제 운영 VOC 분포나 운영 성능을 대표하지 않는다.
- 처리 성공률은 분류 정확도와 다르다. 20건 모두 처리됐지만 주요 항목 완전 일치는 5건이었다.
- 수작업 기준선 시간은 측정하지 않았다. 자동 처리 시간으로 사람 대비 절감률을 계산하지 않는다.
- 이 점수만으로 실제 고객 데이터를 자동 승인하거나 운영에 투입하면 안 된다. 사람 검토가 필요하다.
